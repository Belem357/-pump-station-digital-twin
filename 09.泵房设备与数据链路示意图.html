一、真实机房长什么样（视频里的设备，从左到右走一遍水）

水路 / 管路 水流方向 传感器（本项目要采集的测点） 控制与调速（变频柜 / 控制线）
和咱们项目的对应关系：视频里的变频控制柜 = 咱们要模拟的"大脑"（Modbus 模拟器 + 后端顶替它）；液位传感器、压力传感器 = 咱们数据字典里的 tank_level、pipe_pressure；两台立式泵 = pump_01 / pump_02。
视频里有、但咱们不模拟的：浮球阀、闸阀、止回阀、气压罐、集水坑——这些在 3D 里做静态模型即可（PRD 边界已写明不做多余功能）；若导师希望浮球阀/气压罐也动起来，再补测点。
提醒：本图是按"学校生活供水泵房"的标准配置重绘的。如果你看视频时发现机房里是 3 台泵、或没有气压罐、或多了消毒装置，告诉我，我照视频实际画面改。

二、视频设备 ↔ 本项目模拟方式 对照表

视频机房里的设备它在真实泵房里的作用本项目怎么模拟（对应文档）
市政进水 + 水力浮球阀水位低时自动往水箱补水不模拟补水动作；液位由模拟器手动 / 脚本改动（第 1 周排班表）
不锈钢水箱蓄水缓冲、错峰调蓄tank_body + tank_water_surface（接口规范 3.1 节点表）
液位传感器 / 浮球开关测水箱水深模拟器寄存器 40001 → tank_level（接口规范四）
吸水闸阀检修时关断水流静态模型，无测点
立式多级离心泵 ×2加压供水（一用一备）pump_01 / pump_02：状态 40003/40007、频率 40004/40008、电流、温度（接口规范 3.2）
止回阀防止停泵时水倒流、防水锤静态模型，无测点
压力传感器测出水压力，反馈给变频柜恒压寄存器 40002 → pipe_pressure；报警 >0.8MPa（接口规范四、PRD F6）
隔膜气压罐缓冲压力波动、减少启停次数建议静态模型（待决策，第 5 周前定）
变频控制柜（变频器+PLC）调速、轮换、保护、恒压逻辑Modbus 模拟器 + 后端：启停写线圈 00001~00004，调速写 40020/40021（接口规范四）
集水坑 + 潜污泵排走机房地面渗水不在本项目范围（PRD 边界：不做）
