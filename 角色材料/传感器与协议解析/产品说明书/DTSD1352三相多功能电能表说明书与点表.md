# 第一部分　产品说明书

## 1. 产品概述

DTSD1352 是安科瑞（Acrel）生产的**三相四线多功能电能表**，用于计量三相系统的电压、电流、有功/无功功率、有功/无功电能、功率因数、频率等电量参数，并通过 **RS485 / Modbus RTU** 接口上传。本方案中它负责泵房总进线的电量计量，为数字孪生提供「今日累计耗电量」数据源。

> 与 3.1~3.4 的 4-20mA 模拟量传感器不同，本仪表是**数字通信型**：不需要 AI 模块做 A/D 转换，直接经 RS485 总线 + 网关接入 Modbus TCP。

### 2.1 核实说明（已按厂商官方公开资料核对，2026-10-08）

**① 精度「0.5S 级」里那个 S 是什么（这是个答辩加分点）**

S 表示「**经互感器接入**」（S = 互感器用）。不带 S 的 0.5 级只保证在**额定电流附近**准确；带 S 的 **0.5S 级在很宽的电流范围内都保持 0.5 级精度**。

泵房的实际电流随用水量大幅波动（夜间几乎空载、用水高峰满负荷），**所以 0.5S 比 0.5 更合适**——这个理由答辩时值得主动说。本件与 `pointTable.json`、`devices.json` 统一写 **0.5S 级（有功）/ 2 级（无功）**。

**② 其他可核实规格（已核对，原文未写）**

| 项 | 值 |
|---|---|
| 安装方式 | **DIN35 导轨式**（控制柜里标准安装） |
| 通讯口 | 最大支持 **2 路独立 RS485**（可分别设不同协议），另有 1 路红外 |
| Modbus 从站地址 | **1~247**（原文写"从站地址 1"是典型取值，范围实际到 247） |
| 波特率 | **1200~19200bps 可设**（原文写 9600 是常见取值） |
| 电流规格 | 3×1(6)A（**经互感器接入**）或 3×10(80)A（直接接入） |
| 外形尺寸 | 126×88×69 mm |

**③ 三个区都要装表时注意**：DTSD1352 原生支持多从站，**一个 RS485 口可以挂多台表**（各设不同从站地址），不必每台表配一个网关口。三压改造后 1 总表 + 3 分区表 = 4 台，**② 要处理 4 个从站地址**，`today_kwh` 从 1 个测点变 4 个。详见《共享文档/12.三压分区改造方案 v1.2》第 9.1 节决策 12。

**④ 本仪表是全项目唯一的数字量设备**：其余四类传感器走 4-20mA 模拟量、要经 PLC 的 AI 模块；**只有它走 RS485（Modbus RTU，串口）**，真机需 **RS485→TCP 网关**才能进 Modbus TCP 链路。

## 3. 工作原理

仪表内部专用计量芯片对三相电压、电流（经互感器隔离采样）同步采样，计算各相及合相的有功/无功功率，并对时间积分累加得到电能。计算结果经微处理器整理，通过 RS485 串行总线按 **Modbus RTU** 协议对外提供寄存器读取。

## 4. 通信与换算

**通信方式**：Modbus RTU（RS485 半双工，A/B 两线），从站地址、波特率、校验方式可设。

**电能值与寄存器换算**（对应本方案唯一测点 `today_kwh`）：

```
今日累计耗电量 today_kwh：32 位浮点（IEEE754），占两个保持寄存器，高字在前
工程值(kWh) = float32(高字, 低字) 还原，不做整数缩放
例：12.6 kWh → 高字 0x4149（十进制 16713）、低字 0x999A（十进制 39322）
```

> 说明：DTSD1352 本身给出的是**总累计电能**，要得到「今日累计」需在采集/后端侧做日基准减法。数字孪生中由模拟器 `sensorSim.py` 直接提供 `today_kwh`（带日基数 12.6，见其源码注释），与仪表约定一致。

## 5. 接线

| 端子 | 接法 |
|---|---|
| 电压输入 Ua/Ub/Uc/N | 接三相四线电压（A、B、C、N） |
| 电流输入 Ia+/Ia−、Ib+/Ib−、Ic+/Ic− | 接外部电流互感器二次侧（x/5A） |
| RS485 A / B | 接采集网关 / PLC 的 RS485 总线 A、B（注意 A-A、B-B 对应，勿反接） |
| 辅助电源 L / N | 接 220VAC 供电 |

> ⚠ **安全要点**：电流互感器二次侧严禁带电开路；RS485 总线两端建议加 120Ω 终端电阻；A/B 反接会导致通信不上。

## 6. 安装与使用

1. 仪表安装于配电柜面板 / 导轨，辅助电源与测量电压需正确区分；
2. RS485 总线采用屏蔽双绞线，与动力线分开走线，避免干扰；
3. 首次上电后核对电压、电流显示与实际是否一致，核对从站地址、波特率；
4. 通过网关 / 采集器把 Modbus RTU 转为 Modbus TCP，接入后端。

## 7. 维护与注意事项

- 定期核对电能示数与电费账单是否吻合，防止计量漂移；
- 通信异常先查 A/B 接线、地址、波特率、终端电阻；
- 检修拆卸前先断电，电流互感器二次侧先短接。

## 2. 信号链（电能表 → Modbus TCP 寄存器）

```
DTSD1352 电能表         RS485 总线         网关 / 采集器          PLC / 后端        Modbus TCP
(计量 → Modbus RTU)  →  (A/B 双线)   →  (RTU → TCP 转换)  →  (日基准减法)  →  40012 保持寄存器
    总累计电能            寄存器值            正向有功电能          今日累计 kWh       float32 双字
```

## 4. 换算示例

| 今日累计电能 | IEEE754 十六进制 | 高字（40012） | 低字（40013） |
|---|---|---|---|
| 0 kWh | 0x00000000 | 0 | 0 |
| 12.6 kWh | 0x4149999A | 16713 | 39322 |
| 100.0 kWh | 0x42C80000 | 17096 | 0 |

> **特例说明**：`today_kwh` 是全表唯一 `float32` 测点，占 40012、40013 两个寄存器（所以下一测点 `valve_inlet_opening` 从 40014 开始），高字在前、不做整数缩放，与 `sensorSim.py` 的 `float32ToWords` / `protocolParser.py` 的 `wordsToFloat32` 保持一致。
