# 第一部分　产品说明书

## 1. 产品概述

本温度测点采用「**PT100 装配式铂电阻 + 一体化温度变送器**」组合：PT100 铂电阻感温，一体化变送器将电阻信号转换为**两线制 4~20mA 标准信号**输出，直接接入 PLC / RTU 的模拟量输入（AI）模块，用于泵房两台泵的电机温度监测（1#、2# 泵各一支）。

## 2. 技术参数

| 项 | 值 | 备注 |
|---|---|---|
| 型号 | PT100 | 铂热电阻，0℃ 时阻值 100Ω |
| 品牌 | 通用件（各厂均有） | 麦克、川仪、天康等均可 |
| 量程 | 0~150 ℃ | 覆盖电机温度工作范围 0~120 ℃，留有余量 |
| 输出信号 | 4~20mA DC（两线制） | 4mA=0℃，20mA=150℃，线性 |
| 感温元件 | PT100 三线制 | 三线制消除引线电阻误差 |
| 精度 | 0.5% FS | 满量程误差 ≤ 0.75 ℃ |
| 供电 | 24 VDC | 供电的是**一体化变送器**；24V 是通用变送器的常见规格，但无具体厂商依据 |
| 测温范围（元件） | -200 ~ 500 ℃（典型值） | 本方案变送器整定 0~150 ℃ |
| 保护管 | 装配式不锈钢（典型值） | 以样本为准 |
| 安装方式 | 磁吸 / 螺纹 / 抱箍 | 贴电机壳体或轴承座 |

> 上表「典型值」项为同系列常见参数，实际以产品铭牌 / 样本为准；用户给定的六项（型号、品牌、量程、输出、精度、供电）为确定值。

### 2.1 核实说明（2026-10-08）

**① 这是「组合件」，不是一个型号**

本测点由两件东西组成：**PT100 铂电阻（感温）** + **一体化温度变送器（转 4~20mA）**。所以：

- 「型号 PT100」指的是**感温元件**，不是变送器
- **真正决定 4~20mA 输出特性的是那个变送器**，它的型号本方案未定（通用件）
- 答辩被问"你的型号是什么"时，要说"PT100 铂电阻配一体化变送器"，**不要只说 PT100**

**② 通用件，无厂商货号**

PT100 与一体化变送器都是**通用件**（麦克、川仪、天康等均有），**不对应某个具体厂商货号**，上表数值为行业通行值。答辩时应如实说明，不要编造具体厂商的规格书。

**③ 精度 0.5%FS 的换算**

量程 0~150℃，0.5%FS = **±0.75℃**。而 `pointTable.json` 里该测点的使用上限是 **120℃**（告警裕量到 150℃），所以实际使用的温度段绝对误差更小，**±0.75℃ 完全够用**。

**④ 供电**：原文「两线制典型 12~36 VDC」对通用一体化变送器属常见范围，但**无具体厂商依据**，仅作参考。本项目取 24VDC。

**⑤ 与三压改造的衔接**：三压后温度测点从 2 支变 **6 支**（每台泵一支），型号规格不变。见《共享文档/12.三压分区改造方案 v1.2》。

## 3. 工作原理

PT100 是**铂热电阻**：铂丝阻值随温度升高而近似线性增大，关系为 `R = R₀(1 + αT)`，其中 R₀=100Ω（0℃）、温度系数 α≈0.00385 /℃。**三线制**接法用三根引线（其中一边两根、一边一根）组成电桥，把两根引线的电阻抵消掉，消除长引线带来的测量误差。一体化变送器把测得的电阻值经放大、线性化、温度补偿后，转换为 4~20mA 电流输出。

## 4. 输出特性与换算

4~20mA 与温度成**线性**关系，换算公式：

```
温度 T(℃) = (I − 4mA) / 16mA × 150
输出 I(mA) = 4 + 16 × (T / 150)
```

| 温度 (℃) | 输出 (mA) | 对应项目阈值 / 说明 |
|---|---|---|
| 0 | 4.00 | 量程下限 |
| 26 | 6.77 | 电机初始 / 室温基准（模拟器初值 26.0℃） |
| 50 | 9.33 | |
| 80 | 12.53 | |
| 100 | 14.67 | |
| 120 | 16.80 | 点表使用上限（max） |
| 150 | 20.00 | 量程上限 |

## 5. 接线

分两层接线：

**第一层：PT100 感温元件 → 一体化变送器（三线制）**

| 线色 | 接法 |
|---|---|
| 两根同色（红/红 或 红/蓝） | 接变送器对应端子，构成电桥补偿回路 |
| 一根异色（白） | 接变送器另一侧 |

**第二层：一体化变送器 → AI 模块（两线制 4-20mA）**

| 端子 / 线色 | 接法 |
|---|---|
| 红线（电源 + / 信号 +） | 接 24VDC 正极 |
| 信号线（I+） | 接 AI 模块电流输入正端 |
| 电源负极 | 与 AI 模块电流输入负端（I−）共地 |

**注意**：三线制三根线必须等长、等截面，否则抵消引线电阻的效果打折扣；AI 模块按 4~20mA 电流输入整定。

## 6. 安装与使用

1. 探头贴紧电机壳体（磁吸）或旋入轴承座测温孔（螺纹），保证与测温点良好接触；
2. 远离电机冷却风扇直吹面，否则读数偏低；
3. 首次上电后待输出稳定（数秒）再读数；
4. 检修拆卸前先断电，避免拉扯引线。

## 7. 维护与注意事项

- 定期检查保护管是否松动、引线是否破损；
- 若读数明显漂移，先查接线是否松动、变送器零点是否偏移，必要时重新标定；
- 三线制引线断裂会造成读数异常，需整根更换。
