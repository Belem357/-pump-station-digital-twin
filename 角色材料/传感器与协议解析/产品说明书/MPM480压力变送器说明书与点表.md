# 第一部分　产品说明书

## 1. 产品概述

MPM480 是麦克传感（Micro Sensor）生产的**通用型压力变送器**，用于连续测量与 316L 不锈钢兼容的气体、液体压力。本产品采用**两线制 4~20mA 标准信号**输出，可直接接入 PLC、RTU、二次显示仪表的模拟量输入（AI）模块，是泵房出水总管压力监测的常用选型。

### 2.1 核实说明（已按厂商官方公开资料核对，2026-10-08）

**① 供电**

官方规格为 **15~30VDC**（两线制）。原文写的「两线制典型 12~36 VDC」**在官方资料中查不到依据，已替换**。本项目取 24VDC，落在 15~30VDC 范围内，无影响。

**② 「余量」有两种算法，别混淆**

| 说法 | 出处 | 含义 | 比值 |
|---|---|---|---|
| 「无预留裕量」 | 本件第 4 节 | 传感器量程（1.0）÷ 点表使用上限（1.0） | = 1.0 |
| 「留了 1.25 倍余量」 | 《10.传感器选型说明》3.2 节 | 量程上限（1.0）÷ 报警阈值（0.8） | = 1.25 |

两者说的是**不同的比值，并不矛盾**。选型时的判据是后一条：**先看报警阈值，再选量程上限，最后才看正常工况值**。

**③ 与三压分区改造的衔接（重要）**

三压改造后**高压区需要 0~1.6MPa 量程**（因为报警上限 0.88 × 1.25 = 1.10 > 1.0）；低压区 0~0.6MPa、中压区 0~1.0MPa。也就是**三个区是三种规格的变送器**，将来真采购要报三个量程。详见《共享文档/12.三压分区改造方案 v1.2》第 4.4 节。

**④ 精度**：官方为**典型 0.25%FS、最大 0.5%FS**。本表与 `pointTable.json`、`devices.json` 统一取 **0.5%FS（最大值）**，属保守取值，三处一致。

## 3. 工作原理

采用**硅压阻式（扩散硅）**测量原理：被测介质压力作用在隔离膜片上，通过硅油传递到扩散硅压阻芯片，芯片上的惠斯通电桥受压后阻值变化，输出与压力成正比的微弱电信号；经放大、温度补偿、线性化处理后，转换为 4~20mA 电流输出。

## 4. 输出特性与换算

4~20mA 与压力成**线性**关系，换算公式：

```
压力 P(MPa) = (I − 4mA) / 16mA × 1.0
输出 I(mA) = 4 + 16 × P
```

| 压力 (MPa) | 输出 (mA) | 对应项目阈值 / 说明 |
|---|---|---|
| 0.00 | 4.00 | 量程下限 |
| 0.12 | 5.92 | 停机静压（模拟器零泵基准） |
| 0.25 | 8.00 | |
| 0.50 | 12.00 | |
| 0.80 | 16.80 | 高压报警线（pressureHigh） |
| 1.00 | 20.00 | 量程上限 |

## 5. 接线（两线制）

两线制 4~20mA 只有两根线：既供电又传信号。接线方式：

| 端子 / 线色 | 接法 |
|---|---|
| 红线（电源 + / 信号 +） | 接 24VDC 正极 |
| 信号线（I+） | 接 AI 模块电流输入正端 |
| 电源负极 | 与 AI 模块电流输入负端（I−）共地 |

**注意**：不得接反极性；AI 模块须按 4~20mA 电流输入模式整定；两线制不能与三线制/四线制混接。

## 6. 安装与使用

1. 变送器通过螺纹（M20×1.5）**垂直或水平安装**在取压点上，取压口应选在管路上方或侧面，避免在底部积水/杂质；
2. 测量液体时，宜加**针型阀 / 缓冲**，避免水锤冲击膜片；
3. 首次上电后待输出稳定（数秒）再读数；
4. 检修、拆卸前先关闭取压阀并泄压，再拆卸变送器。

## 7. 维护与注意事项

- 定期检查取压管是否堵塞、膜片是否结垢或受损；
- 若读数漂移，先查取压管是否堵塞、零点是否偏移，必要时重新标定；
- 长期停用应泄压、清洗、干燥后存放。

## 2. 信号链（4-20mA → Modbus 寄存器）

```
MPM480 压力变送器         AI 采集模块            PLC / 控制器         Modbus TCP
(硅压阻 → 4~20mA)      →  (4~20mA → 0~1.0MPa)  →  (×1000 缩放取整)  →  40002 保持寄存器
    0MPa → 4mA              4mA → 0 MPa             0 → 0              0
    1MPa → 20mA            20mA → 1.0 MPa         1000 → 1000        1000
```
