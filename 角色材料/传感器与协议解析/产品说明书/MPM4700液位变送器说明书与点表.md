# 第一部分　产品说明书

## 1. 产品概述

MPM4700 是麦克传感（Micro Sensor）生产的**投入式静压液位变送器**，用于连续测量水、油等液体的液位高度。本产品采用**两线制 4~20mA 标准信号**输出，可直接接入 PLC、RTU、二次显示仪表的模拟量输入（AI）模块，是泵房/水箱液位监测的常用选型。

### 2.1 核实说明（已按厂商官方公开资料核对，2026-10-08）

**① 量程 0~2mH₂O 的来源**

MPM4700 的**标准量程档位是 3.5 / 7 / 10 / 20 / 35 / 70 / 100 / 200 mH₂O——其中没有 2m 这一档**。本方案的 0~2mH₂O 来自「**量程缩放**」功能：官方说明「量程缩放最小为基本量程的 1/5」，即由 **10m 基本量程缩到 1/5** 得到。

**② 精度 0.5%FS 的来源**

MPM4700 非缩放档的综合精度典型值是 **±0.1%FS**；但官方明确说明**小量程段经量程缩放后，综合精度典型值为 ±0.5%FS**。本项目用的正是缩放档，**所以 0.5%FS 是厂商给定指标，不是随意填写**。

**③ 为什么选 2m 而不选最小标准档 3.5m**

精度按满量程的百分比计算，**量程越小，绝对误差越小**：

| | 0~2mH₂O（10m 档缩放） | 0~3.5mH₂O（最小标准档） |
|---|---|---|
| 覆盖 150cm 水箱 | 够（1.33 倍余量） | 够（2.33 倍余量） |
| 精度 | ±0.5%FS | ±0.5%FS |
| **换算成绝对误差** | **±1.0 cm** | ±1.75 cm |

所以**用刚好覆盖的缩放档，比用宽松的标准档更准**。选型理由详见《共享文档/10.传感器选型说明 v1.2》第 3.1 节。

**④ 供电范围（官方）**

MPM4700 按接口型式不同：RS485 型 **10~28VDC**、HART 型 **12~30VDC**、本安型 10~12VDC（经安全栅）。**本项目取 24VDC，落在上述范围内。** 4~20mA 两线制的具体规格以订货样本为准。

> ⚠️ 原文写的「两线制典型 12~36 VDC」**在官方资料中查不到依据**，已按上述核实结果替换。24V 本身在范围内，不影响本项目。

## 3. 工作原理

采用**静压法**测量液位：液体静压 `P = ρ·g·h`，与液位高度成正比。变送器的传感器膜片感受液柱静压，经「导气电缆」内的毛细管把液面上方大气压引到传感器背面，两者相减即可**抵消大气压变化**，从而只保留液柱压力。该压力经放大、温度补偿后，线性转换为 4~20mA 电流输出。

## 4. 输出特性与换算

4~20mA 与液位成**线性**关系，换算公式：

```
液位 h(m) = (I − 4mA) / 16mA × 2
输出 I(mA) = 4 + 16 × (h / 2)
```

## 5. 接线（两线制）

两线制 4~20mA 只有两根线：既供电又传信号。接线方式：

| 端子 / 线色 | 接法 |
|---|---|
| 红线（电源 + / 信号 +） | 接 24VDC 正极 |
| 信号线（I+） | 接 AI 模块电流输入正端 |
| 电源负极 | 与 AI 模块电流输入负端（I−）共地 |

**注意**：不得接反极性；AI 模块须按 4~20mA 电流输入模式整定；两线制不能与三线制/四线制混接。

## 6. 安装与使用

1. 探头**垂直投入**液底（或悬挂于固定高度），避免贴壁、避免被进水管水流直冲；
2. 电缆用卡扣固定，**导气管口不得进水**，否则大气压补偿失效、读数漂移；
3. 远离搅拌器、进水口、气泡集中的区域，减少波动；
4. 首次上电后待输出稳定（数秒）再读数；
5. 检修、清池时先断电再提出探头，避免膜片受冲击。

## 7. 维护与注意事项

- 定期清理探头膜片附着物（结垢、泥沙），防止灵敏度下降；
- 检查电缆有无破损、导气管是否通畅；
- 若读数明显漂移，先查导气管是否进水、零点是否偏移，必要时重新标定；
- 长期停用应清洗、干燥后存放。
