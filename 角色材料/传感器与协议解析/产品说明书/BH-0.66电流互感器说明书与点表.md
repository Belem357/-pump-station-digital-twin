# 第一部分　产品说明书

## 1. 产品概述

本电流测点采用「**BH-0.66 电流互感器 + 电流变送器**」组合：BH-0.66 穿心式电流互感器把电机的一次大电流按比例变换成二次小电流，电流变送器再将其转换为**两线制 4~20mA 标准信号**输出，直接接入 PLC / RTU 的模拟量输入（AI）模块，用于泵房两台泵的电机电流监测（1#、2# 泵各一支）。

### 2.1 核实说明（2026-10-08）

**⚠️ ① 原文「穿心式…无需断线」自相矛盾，已修正**

「**穿心式**」是**闭合磁路**结构，电缆必须从中心孔**穿过去**——所以要**先断开电缆一端**才能套入。「**无需断线**」只在「**开口式 / 开合式**」结构上成立（磁路可以打开、卡到已有电缆上）。

**这两个特性是互斥的，原文写反了。** 已把备注改为正确表述。

**⚠️ ② 与 `devices.json` 的口径冲突（需 ① 或 ⑥ 定）**

| 出处 | 说法 |
|---|---|
| 本件 | 型号 `BH-0.66`，**穿心式** |
| `代码/backend/devices.json` | `"note": "开口式安装，不停电即可装拆"` |

**`BH-0.66` 里的「0.66」是额定电压 0.66kV，不是开口式编号。** 所以：

- 若坚持 `BH-0.66`，那就是**穿心式，要断线**，`devices.json` 的"开口式"要改掉
- 若要保持"不停电安装"这个卖点，**型号要换成开口式系列**（如 LMK 类开合式互感器），`devices.json` 的型号也要改

**建议**：统一为「BH-0.66 穿心式」，把 `devices.json` 的"开口式安装"改成"穿心式（需断开电缆）"，答辩时不再提"不停电"。**改动位置**：`devices.json` 的 `ct.sensor.note` + `pointTable.json` 的 `sensors.current.note`。

**③ 通用件的说明**

BH-0.66 是**通用件**（正泰、德力西、人民电器等均有），**不对应某个具体厂商货号**，上表数值为行业通行值。答辩时应如实说明，不要编造具体厂商的规格书。

**④ 供电**：本测点真正用电的是**电流变送器**，不是互感器（互感器是无源器件，靠电磁感应）。原文「两线制典型 12~36 VDC」对通用变送器属常见范围，但**无具体厂商依据**，故仅作参考，不作为确定性参数。

## 3. 工作原理

**电流互感器（CT）**基于电磁感应：被测载流导线穿过互感器中心孔（作为一次绕组，通常 1 匝），铁芯中的交变磁场在二次绕组感应出按匝数比缩小的电流（20A → 5A）。**电流变送器**把二次侧的交流小电流经取样、整流、滤波、线性化、温度补偿后，转换为与一次电流成正比的 4~20mA 直流信号。

## 4. 输出特性与换算

4~20mA 与一次电流成**线性**关系，换算公式：

```
电流 I(A) = (I_out − 4mA) / 16mA × 20
输出 I_out(mA) = 4 + 16 × (I / 20)
```

| 电流 (A) | 输出 (mA) | 对应项目阈值 / 说明 |
|---|---|---|
| 0 | 4.00 | 量程下限（停机） |
| 5 | 8.00 | |
| 10 | 12.00 | |
| 15 | 16.00 | 满频约 15A（模拟器 0.30×50Hz） |
| 20 | 20.00 | 量程 / 点表上限 |

## 5. 接线

分两层接线：

**第一层：一次侧（穿心，无需接线端子）**

| 说明 |
|---|
| 电机某相电源线穿过互感器中心孔 1 匝（穿 1 圈，对应 20A 量程；穿 2 圈量程减半为 10A） |

**第二层：电流互感器二次侧 → 电流变送器 → AI 模块（两线制 4-20mA）**

| 端子 / 线色 | 接法 |
|---|---|
| 互感器二次 S1 / S2 | 接电流变送器的电流输入端 |
| 变送器红线（电源 + / 信号 +） | 接 24VDC 正极 |
| 变送器信号线（I+） | 接 AI 模块电流输入正端 |
| 电源负极 | 与 AI 模块电流输入负端（I−）共地 |

> ⚠ **安全要点**：电流互感器二次侧**严禁带电开路**，开路会在二次侧感应出危险高电压；拆卸/接线前必须先断电或先把二次侧短接。

## 6. 安装与使用

1. 互感器套在电机三相中的某一相（单相电流监测即可，三相平衡时一相代表三相）；
2. 中心孔内导线居中，避免贴边导致误差；
3. 变送器固定于控制柜导轨，远离强电磁干扰源；
4. 首次上电后待输出稳定（数秒）再读数。

## 7. 维护与注意事项

- 定期检查互感器是否松动、二次接线是否牢固；
- 若读数明显偏小或为 0，先查是否一相穿错 / 匝数不对、二次侧是否虚接；
- 更换或拆卸前必须断电或短接二次侧，防止开路高压。

## 2. 信号链（一次电流 → 4-20mA → Modbus 寄存器）

```
电机相线一次电流     BH-0.66 互感器      电流变送器           AI 采集模块         PLC / 控制器       Modbus TCP
(0~20A)          →  (变比 20/5A)    →  (二次 → 4~20mA)  →  (4~20mA → 0~20A)  →  (×10 缩放)  →  40005 / 40009
```
