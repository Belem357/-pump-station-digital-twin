# 产品说明书与点表（5 类传感器）

本目录放 **5 类传感器的产品说明书 + I/O 点表**，是 ① 传感器与设备模拟 / ② 协议解析的**建点与解析依据**，也是答辩时"这个器件是什么、怎么接线"的讲解材料。

---

## 一、文件清单

| 文件 | 测点 | 说明 |
|---|---|---|
| `MPM4700液位变送器说明书与点表.md` + `_点表.json` | `tank_level`（40001） | 水箱液位，投入式静压，4-20mA |
| `MPM480压力变送器说明书与点表.md` + `_点表.json` | `pipe_pressure`（40002） | 出水总管压力，4-20mA |
| `PT100温度变送器说明书与点表.md` + `_点表.json` | `pump_01_temp`（40006）/ `pump_02_temp`（40010） | 电机温度，PT100 + 一体化变送器 |
| `BH-0.66电流互感器说明书与点表.md` + `_点表.json` | `pump_01_current`（40005）/ `pump_02_current`（40009） | 电机电流，互感器 + 变送器 |
| `DTSD1352三相多功能电能表说明书与点表.md` + `_点表.json` | `today_kwh`（40012~40013） | 今日耗电量，**全项目唯一的 RS485 数字量设备** |

每个 `.md` 分两部分：**第一部分 产品说明书**（概述 / 技术参数 / 原理 / 换算 / 接线 / 安装 / 维护 / 订货），**第二部分 I/O 点表**（测点定义 / 信号链 / 寄存器映射 / 换算示例）。

## 三、已汇总进总点表（重要）

5 份 `_点表.json` 里的 `sensor` 段**已并入 `代码/backend/pointTable.json` 的 `sensors` 段**（按 `level` / `pressure` / `temperature` / `current` / `energy` 五个键，每个键用 `tags` 指回它服务的测点）。

所以：

- **总点表 `pointTable.json` 现在是"地址 + 缩放 + 传感器型号"的唯一数据源**
- 本目录的 `_点表.json` 是**来源留档**，不要再直接改它们
- **改型号 / 量程 / 精度要同时改三处**：`pointTable.json` 的 `sensors` 段、本目录对应的 `.md`、以及 `代码/backend/devices.json`（前端讲解卡片读后者）

> 已确认：`sensorSim.py` / `protocolParser.py` / `main.py` / `linkCheck.py` 都是**按 key 取字段**（`config["holdings"]` 等），不遍历顶层 key，所以新增 `sensors` 段**不影响任何程序**。

## 五、⚠️ 待确认：一批（1 项）

**BH-0.66 到底是「穿心式」还是「开口式」？**

| 出处 | 说法 |
|---|---|
| 本目录 | `BH-0.66`，**穿心式**（`.66` = 额定电压 0.66kV，不是开口式编号） |
| `代码/backend/devices.json` | `"note": "开口式安装，不停电即可装拆"` |

**两者只能选一个**：

- **选穿心式**（推荐，与型号相符）→ 把 `devices.json` 的"开口式安装"改掉，答辩时不再提"不停电安装"
- **选开口式** → 型号要换成开合式系列（如 LMK 类），`devices.json` 与 `pointTable.json` 的型号都要改

**建议前者**，改动最小且与型号自洽。**需 ① 或 ⑥ 拍板。**

## 六、怎么用（按角色）

| 角色 | 看哪部分 |
|---|---|
| **① 传感器与设备模拟** | 每份的**第一部分**（规格、换算、接线）+ 第二部分的寄存器映射（建点时照 `min`/`max`/`scale` 填）；配合《05.Modbus建点表》 |
| **② 协议解析** | 每份的**第二部分第 2、3 节**（信号链 + 寄存器映射 + 换算公式）；改映射时以 `pointTable.json` 为准，本目录用于理解"为什么这么换算" |
| **③ 后端 / ⑤ 前端** | 只需知道单位与量程；讲解卡片的数据在 `devices.json` |
| **答辩** | 第一部分的技术参数 + 换算表；**尤其第 2.1 节的"核实说明"**，那里写了能回答追问的关键信息 |
