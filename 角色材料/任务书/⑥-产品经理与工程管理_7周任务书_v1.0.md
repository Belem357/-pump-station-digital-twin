#### W1-2 改 PRD F9：自动模式从"液位控制"改成"恒压控制" ｜ 0.5 天

**要做什么**：把 PRD 里 F9 的自动模式逻辑重写。

**现在是**（PRD F9）：
```
液位 ≥ 90cm → 启泵
液位 ≤ 40cm → 停泵
```

**改成**（恒压控制）：
```
出水压力 < 设定值        → 升频（或启泵加压）
出水压力 = 设定值        → 稳频
出水压力 > 上限 且小流量 → 停泵，靠气压罐内压力维持供水
```

**连带要改的三处**（《12》第 1.2 节的表）：

| | 现在 | 恒压变频后 |
|---|---|---|
| `pipe_pressure` | **只看**——监控量 + 超压报警 | **控制量**——变频器的反馈输入 |
| 液位 | **控制量**——自动模式靠它启停泵 | **降级为保护量**——只做低液位联锁（F10）+ 高液位防溢流 |
| 报警逻辑 | 越上限报警（>0.8 MPa） | **偏离设定值报警**（高了低了**都**报） |

> ⚠️ **超压只报警不停泵**这条规则**保留**——停泵会导致高层住户断水。

| 区 | 压力设定值 | 报警上限 | 报警下限 | 变送器量程 | 寄存器存值范围 |
|---|---|---|---|---|---|
| **LO 低压** | **0.30 MPa** | 0.38 | 0.24 | **0~0.6 MPa** | 0 ~ **600** |

## 四、导师可能问的问题（提前准备口径）

| 问题 | 怎么答 |
|---|---|
| **"PRD 里写的是 2 台泵，你这怎么 6 台？"** | 三压分区是**单个泵房内部的分区结构**（楼宇分区供水，18 层住宅分高中低三区是标准做法），**不是 PRD 排除的"多泵房/多站点集中管理"**。**这是"单站深化"，不是"多站扩张"。** |
| **"气压罐为什么只有一个？三区压力不一样，一个罐稳得住吗？"** | **主动承认是简化**。真实的分区供水通常每区各有稳压罐，本项目按"公共一个"建模，属有意简化。**别等导师问出来才说。** |
| **"模型怎么布局这么挤？"** | 模型走"加区"路线，**侧重把供水链路和各设备关系表达清楚，不做完整工程还原**。 |
| **"一共用了多少设备？"** | **主设备 9 台件（电机 2 台）→ 改造后 6 台泵 6 台电机**；电气 7 件；仪表 7 支只。**具体数字看《13 设备台账》。** |
| **"进水阀怎么是手轮？不是要远程控制吗？"** | **如实说**：模型是最初建的，进水阀建成了手轮（手动阀），电动执行机构为后续预留。**不要主动展示"远程调进水阀开度"。** |
| **"出水总管上装的是压力表还是变送器？"** | 模型上是**机械指针表**，系统采集用**变送器**。实机上两者并存是常规做法（机械表供现场巡检、变送器供系统采集）。 |
| **"这个泵房有真实设备吗？"** | **本项目没有真实泵房**，全部设备由 Modbus 模拟器以软件顶替，但 **Modbus TCP 协议是真的保留**，将来换真 PLC 只改连接地址。 |
