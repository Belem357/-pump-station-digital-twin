## 怎么传（三选一，推荐第 1 个）

### 办法一：拖文件夹（最简单）

1. 在自己电脑上建一个文件夹，**名字就用你的角色名**（例如 `传感器`）
2. 把截图、代码文件都放进这个文件夹
3. 打开仓库页面 → 进到 `demo/第1周/`
4. 点 **Add file** → **Upload files** → 把**整个文件夹拖进去**
5. 下方点绿色的 **Commit changes**

### 办法二：只传一个文件

同上，只是不建文件夹，直接把文件拖进去。**文件名前面带上你的角色名**，例如 `传感器_改数值截图.png`。

### 办法三：会 git 的话

```bash
git pull
mkdir -p demo/第1周/你的角色名
# 把文件放进去
git add .
git commit -m "第1周 demo - 你的角色名"
git push
```

## 传不上去？（报错说没权限）

说明仓库还没把你加成协作者。**把你的 GitHub 账号名发到群里**，让组长去仓库的 `Settings` → `Collaborators` 里加一下，就能传了。

## 提醒

- **不要传大文件**（超过 25MB 网页传不上去）。录屏尽量压小，或者只传截图。
- 传错了不用慌，GitHub 上可以删掉重传。
- 传完在群里说一声"我传完了"，组长要清点六个人。
